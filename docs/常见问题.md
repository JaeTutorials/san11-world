# 常见问题

**启动游戏时报「固定劇本資料讀取失敗」或「記憶體不足」**
游戏目录的路径里有中文。建一个英文路径的目录联接（见[快速上手](快速上手.md)第 1 步），从那个路径启动。
worldmod 发现路径有问题时会自动改从目录联接重新启动，没有联接时会弹窗告诉你怎么建。

**`san11kit.py doctor` 说 san11pk.exe 版本不对**
worldmod 只支持一个特定版本的 `san11pk.exe`，别的版本里代码的位置不一样，打补丁会出错，所以它会直接拒绝。

**游戏能启动，但地图还是原版的中国**
启动的是 `san11pk.exe`（原版）而不是 `san11pk_world.exe`。worldmod 按启动程序的名字读 `worldmod.ini` 里的同名一节，
原版那一节就是原版地图。

**改了剧本 JSON，游戏里没变化**
要开新游戏，读旧存档看不到剧本的改动。确认运行过 `python san11kit.py scenario`，并且它说「已写入」。

**改了城市数以后读不了存档**
城市数不同的存档互不通用。`project.json` 的 `save_dir` 让每份配置的存档放在不同的文件夹，不会互相覆盖。

**新武将在武将列表里看不到**
用了 700~849 号武将槽（游戏把这一段当成异族头目等特殊人物，列表里不显示）。不写 `slot`，让编译器自动分配就不会有这个问题。

**有些城走不到**
`san11kit.py world` 的输出里会列出「步行走不到」的城：都是海岛城（英国、日本、斯里兰卡……），要坐船。
如果有大陆上的城也走不到，用编辑器在它和邻城之间画一条主径。

**点不了鼠标**
自动跳过只在它点击的一瞬间接管鼠标，你点一下鼠标、按回车或 Esc 它就停。还不行就把 `worldmod.ini` 里的 `auto_skip=1` 改成 0。

**出错了要找人帮忙**
把这几样发过去：`san11kit.py doctor` 的输出、游戏目录里的 `worldmod_<启动程序名>.log`、出错时的截图。

**想改游戏本身的代码（不只是数据）**
读 [TUTORIAL.md](../TUTORIAL.md)。worldmod 的源码在 `worldmod/src/`，用 `python san11kit.py dll` 编译（需要 Visual Studio 2022 生成工具）。
补丁表由 `tools/patchgen/build_patches.py` 生成，它需要一份原版 exe 放在 `backup/san11pk.exe.orig`。
