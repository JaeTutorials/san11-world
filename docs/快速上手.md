# 快速上手

从零开始，到在游戏里看到欧亚大陆。全部操作在「命令提示符」（cmd）里完成，每条命令都可以直接复制。

## 0. 准备

1. **游戏**：正版《三国志11威力加强版》，装好、能正常运行。
2. **Python**：从 python.org 安装 Python 3.9 或更新的版本，安装时勾选「Add Python to PATH」。
3. **本项目**：从发布页（GitHub 的 Releases）下载 `san11-world-版本号.zip`，解压到任意目录，比如 `D:\san11kit`。在这个目录里打开命令提示符（在资源管理器地址栏输入 `cmd` 回车）。
4. **装 Python 库**：

```bat
pip install -r requirements.txt
```

5. **worldmod 的 d3d9.dll**：发布包里已经有了（`worldmod\build\d3d9.dll`），跳过这一步。
   用 git 克隆源码的人没有它：从发布包里拿一个放进 `worldmod\build\`，
   或者装了 Visual Studio 2022 生成工具（C++ 桌面开发）的话自己编译：`python san11kit.py dll`。

## 1. 游戏目录要用英文路径

游戏在含中文的路径下（比如 `D:\游戏\三国志11`）读不了剧本，会报「固定劇本資料讀取失敗」。
最简单的办法是建一个英文路径的「目录联接」，它指向同一个文件夹，不占空间：

```bat
mklink /J C:\San11PK "D:\游戏\三国志11"
```

之后一律用 `C:\San11PK` 这个路径。游戏目录本来就是英文路径的话跳过这一步。

## 2. 生成项目文件

```bat
python san11kit.py init --game "C:/San11PK"
```

会在项目目录里生成 `project.json`，用记事本打开就能改。几个常用设置：

| 设置 | 意思 | 默认 |
|---|---|---|
| `game_dir` | 游戏目录（英文路径） | init 时填的 |
| `cities` | 城市总数，含光荣原有的 42 座，42~1000 | 500 |
| `data_name` | 世界数据放在游戏目录里的哪个文件夹 | world_custom |
| `exe` | 用哪个启动程序玩 | san11pk_world.exe |
| `save_dir` | 存档放在游戏目录里的哪个文件夹（和原版存档分开） | UserData_kit |
| `scenarios` | 要编进去的剧本 JSON 列表 | 欧洲势力的例子 |

## 3. 检查环境

```bat
python san11kit.py doctor
```

它会逐项列出「好」和「缺」，每个「缺」后面都写着用哪条命令补上。后面每一步做完都可以再运行它看看。

## 4. 下载公开数据

```bat
python san11kit.py download
```

下载 NOAA 的全球高程数据（约 470 MB）和 Natural Earth 的河流、湖泊数据。只需要下载一次。
网络不好可以按它显示的网址手动下载，放到 `data\raw\` 里对应的文件夹。

## 5. 安装

```bat
python san11kit.py setup
```

做三件事：从你的游戏里提取中国地图（光荣的数据不随项目发布，所以要现场提取）、把高程数据转换成工具要用的格式、
把 worldmod 装进游戏目录并生成启动程序 `san11pk_world.exe`。原版的 `san11pk.exe` 不会被改动。

## 6. 生成世界

```bat
python san11kit.py world --fresh
```

第一次要加 `--fresh`，从高程数据生成整个世界的地形，然后选城、划领地、修路、转换 14 个剧本、编译你的剧本。
整个过程几分钟。以后只改了城市数或剧本，就不用加 `--fresh`，快很多。

## 7. 开始游戏

```bat
python san11kit.py play
```

或者直接双击游戏目录里的 `san11pk_world.exe`。选「新游戏」，第一个剧本（184 年）里在「切換顯示」的势力列表中能找到例子里的「歐洲」势力。

原版的 `san11pk.exe` 仍然是原版游戏，两者互不影响。

## 出问题时

- 先运行 `python san11kit.py doctor`。
- 游戏目录里的 `worldmod_san11pk_world.log` 记录了 MOD 每次启动做了什么，出错时把它发给别人看。
- 更多见 [常见问题](常见问题.md)。
