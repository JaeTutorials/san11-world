# 三国志11 世界地图开发工具包

在原版《三国志11威力加强版》的基础上，把 200×200 格的中国地图扩展成 1800×1000 格的欧亚大陆，城市从 42 座扩到 500 座（实测；工具允许到 1000 座），并提供一整套让剧本作者自己做地图和剧本的工具。

- 光荣的中国地形原封不动地嵌在世界中间，周围是按真实高程生成、再校准成光荣画风的地形
- 新城市按真实地理位置摆放，领地像拼图一样按山脉河流划分，城市之间自动修好道路
- 中地图可以缩放、拖动，小地图跟随镜头，开场动画和剧情对话可以自动跳过
- 剧本用一个 JSON 文件描述：新势力、新武将、城市归属、外交关系，一条命令编进游戏
- 势力、军团上限跟着城市一起扩：常规势力最多 59 个（光荣是 42），见[地图与城市](docs/地图与城市.md)
- 不修改游戏文件：所有改动由一个 `d3d9.dll` 在游戏运行时完成，删掉它就回到原版

## 五分钟上手

需要：Windows、正版《三国志11威力加强版》、Python 3.9 以上。

从 [Releases](../../releases) 下载最新的 `san11-world-版本号.zip`（含编译好的 `d3d9.dll`），解压，在解压出的目录里打开命令提示符：

```bat
pip install -r requirements.txt
python san11kit.py init --game "C:/San11PK"
python san11kit.py doctor
python san11kit.py download
python san11kit.py setup
python san11kit.py world --fresh
python san11kit.py play
```

每一步做什么、出错怎么办，见 [docs/快速上手.md](docs/快速上手.md)。

## 目录

```
san11kit.py            总入口，所有常用操作都从这里开始
project.example.json   项目设置的例子（init 会生成你自己的 project.json）
scenarios/             剧本 JSON（例子：europe_184.json，184 年剧本加一个欧洲势力）
data/                  城市候选表等小文件；生成的大文件和从游戏提取的数据也放这里（不进版本库）
tools/                 每一步的脚本（san11kit.py 按顺序调用它们；make_release.py 打发布包）
  editor/              地图和城市编辑器（浏览器里用）
  patchgen/            从补丁点清单生成补丁表（改游戏代码的人才用）
worldmod/              游戏里运行的 d3d9.dll 的 C++ 源码和补丁表
docs/                  给使用者的文档
.github/workflows/     推送版本标签时自动编译 d3d9.dll、创建发布
*.md（根目录）          逆向笔记和技术文档
```

## 法律说明

这是非官方的爱好者作品，与光荣特库摩（KOEI TECMO）无关。项目里不包含、也不分发任何游戏文件：
中国地图等光荣的数据由 `san11kit.py setup` 从你自己安装的游戏里现场提取。worldmod 只支持一个特定版本的
`san11pk.exe`（会自动检查，版本不对就不会打补丁）。

公开数据：高程来自 NOAA ETOPO 2022，河流湖泊来自 Natural Earth，均为公有领域。
